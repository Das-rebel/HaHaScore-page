## The page's design language

Matches the video brand exactly:
- Bg `#0D0A14` (deep violet-black), cards `#161022`
- Purple `#A78BFA`, gold `#FBBF24`, pink `#F472B6`, teal `#5EEAD4`
- Mono font stack (SF Mono / Menlo), system sans (SF Pro / Inter)
- Self-contained — no fonts loaded from CDNs, no tracking scripts, no external CSS

The "how it's being watched" section is the centerpiece — an animated SVG retention curve with the gold-set laugh markers overlaid at their exact launch-video timestamps. Self-referential: the page shows the model's predictions aligning with the audience's behavior.
